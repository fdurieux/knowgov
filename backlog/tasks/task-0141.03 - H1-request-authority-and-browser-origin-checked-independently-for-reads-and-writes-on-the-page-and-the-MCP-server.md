## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A request whose Host and Origin both name the same foreign authority must not authorise a local operation. Accepted authorities and origins come from trusted configuration derived from the listener, never from the request; forwarded headers count only behind an explicitly trusted proxy; a token and an origin check are independent. The Neo4j Browser guide's cross-origin GET and OPTIONS keep working.
