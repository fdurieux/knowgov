## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The cheapest way to learn whether the J-F arms abstain because of size or because of the task: a plan turn that names the modules, then one reply per module, assembled into a directory in the layout the oracle expects (src/jef, a jdl_adapter.py, a jef-data entry), then graded by the pristine suite. No tools, no code execution by the arm, the same JSON vocabulary per reply. The subject's manifest says the layout; CargoQuote keeps its one-reply arm. The result decides whether subtasks .02 and .03 are built: if the arms still abstain or the oracle grades nothing, the story records that and stops.
