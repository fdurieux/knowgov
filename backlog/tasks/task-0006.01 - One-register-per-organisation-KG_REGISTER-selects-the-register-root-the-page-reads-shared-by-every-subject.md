## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The maintainer's intent (2026-11-01): one register per organisation, with every subject of that organisation in it, and a client's instance reading its own register. Today the page reads one fixed path, demo/register, the public register vendored at a tag; the source card assumes a vendored copy with a SOURCE.md; and one line of register_view.py names CargoQuote's export folder by date where the subject's export_manifest already says which manifest to read.
