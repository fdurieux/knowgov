## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Decision-0013 (proposed to the coordinator): option 2.
1. Neo4j: a writer's whole unit in one explicit transaction (store_neo4j._Unit); schema statements before it (constraints measured once per handle; the import index dropped after commit); a deferred wipe as the unit's first statement.
2. Neo4j: a lease in a _KgPublication node (owner, fencing epoch, expires, heartbeat), acquired at writer open, StoreBusy after KG_NEO4J_LOCK_TIMEOUT; a takeover of an expired lease closes any gap and terminates the former owner's unit transaction by its metadata.
3. Neo4j: publication under a sequence lock (begin raised in its own transaction, end matched in the unit's); a failure after begin closes the gap; a read handle pins (begin,end) and checks after every port read (StoreChanged).
4. Port: StoreChanged, StoreFenced, store.read(fn) retrying; the page's compound reads and the MCP server's _with_store retry; the projection decided under the run lock, StoreBusy 409.
5. rdflib: S1's lock and atomic replace; publish only while the lock file at the path is the one held.
6. The publication node outside every evidence statement (wipe, export, census): record, D1, D2 and Turtle unchanged.
7. tools/check_snapshots.py SNAP-01..07 on a disposable store, in harness.yml (rdflib) and demo.yml (Neo4j); tests/test_store_generations.py; docs/security.md, CHANGELOG contract change, CLAUDE.md.
