## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Neo4j Browser manual documents ?cmd=edit&arg=<query> to pre-fill the editor from a page link without running anything, and ?connectURL= which renderStore() already builds. Whether both combine in one URL, and whether a query of this length survives URL encoding in the editor, is untested (investigation of 2026-11-02). The page runs nothing; the Browser runs nothing on an edit command.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->

- [ ] #3 demo/README.md says, in the adopter register, that the link pre-fills the editor and that a run wipes the projection first

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implementation (commit on the session's worktree, to land on claude/impact-cypher after TASK-0024.01 merges): server.browser_edit_url(text) = KG_BROWSER_URL + /browser/? + urlencode(connectURL=bolt://neo4j@<host>:7687, cmd=edit, arg=<text>) with quote (spaces %20, + as %2B); impact_view() gives cypher.browser {rows, paths}; register_view.with_cypher(browser=) puts the link on each code item and adds two controlled sentences; index.html renders 'open in the Browser' beside the copy button (target _blank, rel noopener). demo/tools/check_impact_cypher.py: for every node of GET /api/register, the arg of both links from GET /api/register/impact/<id> through console_query; rows equal the walk's edges on (from, relationship, to, link state, owner, evidence), paths' distinct relationships equal the edge count and the start is returned; the default start's line is tagged; exit 0 iff every node agrees. demo.yml runs it after the saved queries. README: a passage on the links, the wipe, the Browser 5.26.0 observation; the EC2 note covers the links too.

GUI finding (Playwright on Chromium against the local Neo4j 5.26.0 Browser): ?cmd=play&arg=start opens the guide frame, so URL commands reach the Browser; ?cmd=edit&arg=<query> leaves the editor empty for every shape tried (RETURN 1, quotes, =, newlines, a comment, brackets, the full paths form at 2.5 kB), with and without connectURL, first and second visit. Cause in the bundle (app-60700872178c3c03269e.js): populateEditorFromUrlEpic emits SET_CONTENT one millisecond after APP_START; the editor subscribes to SET_CONTENT in a useEffect after it mounts (bus.take(SET_CONTENT, ...) then setValue), so the message is sent before anyone listens; play goes through the command executor instead. URL_ARGUMENTS_CHANGE, the other trigger, is Desktop's only. connectURL took (bolt://localhost:7687 and the user pre-filled). The link therefore ships as the manual documents it, with the panel sentence and the README saying the editor can open empty and the copy button holds the same text; the stack job verifies what the Browser would receive: the arg decodes to the listed text, replicated by the Browser's own parsing (literal + to space, decode, arg up to & or #), and runs to the walk.

Verification: python tests/run_tests.py 86 of 86. Live against Neo4j 5.26.0 with the register projected: check_impact_cypher.py 'every node agrees: 56 nodes, both forms', exit 0. Playwright on the page: the walk from the default start shows two 'open in the Browser' links (new tab, noopener), the first link's arg equals the pre's text, no page errors.
