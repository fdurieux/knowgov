## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Neo4j Browser manual documents ?cmd=edit&arg=<query> to pre-fill the editor from a page link without running anything, and ?connectURL= which renderStore() already builds. Whether both combine in one URL, and whether a query of this length survives URL encoding in the editor, is untested (investigation of 2026-11-02). The page runs nothing; the Browser runs nothing on an edit command.
