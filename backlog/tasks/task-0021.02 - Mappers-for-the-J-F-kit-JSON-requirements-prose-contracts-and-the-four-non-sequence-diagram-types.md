## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The harness's extraction registry (harness/extract.py MAPPERS) covers markdown requirements, decision tables, spec, OpenAPI, sequence diagrams, C4 containers, BPMN, DMN, Gherkin and links. The J-F kit's requirements are a JSON list of EARS statements with id, kind and basis; its 14 contracts are prose markdown with tables and exact strings; its component, class, activity and state diagrams have no mapper. Each new mapper emits entities, fragments with digests and assertions as the existing ones do, so the rules, the gate and the census work unchanged. The DMN, Gherkin and sequence mappers are reused as they are.
<!-- SECTION:DESCRIPTION:END -->
