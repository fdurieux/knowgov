## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
After TASK-0023 the adapter holds the right query with a literal start that names one subject's register id. The page should list it with the register view's impact_default substituted, so that no module under harness/ or demo/app names a subject's id (task-0002), and the impact panel should carry the same text with the id the viewer typed. renderDetail knows heading, text, list and table; it needs a code section with a copy button. The query text is data, not a controlled sentence; every new sentence keeps to the glossary and twenty words.
