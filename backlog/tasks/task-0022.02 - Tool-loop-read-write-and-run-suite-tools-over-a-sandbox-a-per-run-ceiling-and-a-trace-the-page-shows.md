## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The arm as an agent: a turn loop with three tools (read a document or bundle part, write a file into the sandbox, run the scenario's own suite or a named feature of it) over a per-run sandbox directory, ending with a decision and an assumptions file. The scenario's suite is the arm's feedback, as the record's rebuilds had it; the pristine suite stays the oracle. The subject's manifest names the suite command, the layout and the tool set. A per-run ceiling in calls, dollars and wall time; a trace file of every turn and tool call that the page shows under the Generate box. Tool calling is taken from the OpenAI chat completions API; an endpoint without it is reported, not worked around.
<!-- SECTION:DESCRIPTION:END -->
