## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The arm as an agent: a turn loop with three tools (read a document or bundle part, write a file into the sandbox, run the scenario's own suite or a named feature of it) over a per-run sandbox directory, ending with a decision and an assumptions file. The scenario's suite is the arm's feedback, as the record's rebuilds had it; the pristine suite stays the oracle. The subject's manifest names the suite command, the layout and the tool set. A per-run ceiling in calls, dollars and wall time; a trace file of every turn and tool call that the page shows under the Generate box. Tool calling is taken from the OpenAI chat completions API; an endpoint without it is reported, not worked around.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. harness/agent.py: a turn loop over the chat completions API with tool calling (streamed, tool-call deltas accumulated), four tools: read_document(path), write_file(path, content) confined to the run's sandbox, run_suite(feature|null) through the subject's oracle script, finish(decision, assumptions, questions, claims); a per-run ceiling in calls, dollars and seconds (KG_AGENT_MAX_CALLS/USD/SECONDS, documented defaults) that ends the run with decision abstain and the reason; a trace of every turn and tool call with tokens, cost and elapsed seconds, written beside the run; the responder is injectable so tests run without a client. 2. Subject manifest [arms] kind = reply (default, CargoQuote unchanged) or agent, with [arms.agent] layout prose for the prompt and the kit artefact that is the scenario's suite; the oracle script gains run_feedback(sandbox, features) that runs the scenario's planted feature files over its own steps against the sandbox, and run_artifact(dir) grades it; measures.run_suite accepts a directory. 3. run.py dispatches on the kind; an agent run records M1..M6 as today plus trace summary and a bundle of the sandbox as the run's code text for the page. 4. harness/policy.md: the QUALIFIED rule says what isolation costs (one named constant or one marked comment per key, no restructuring). 5. Page: per-run table gains turns and tool calls; a Trace section per run under the Generate box; the oracle section unchanged. 6. Tests with a scripted responder and a stub oracle; the subject-name guard holds; demo/README.md documents the agent arm, the sandbox rule and the ceilings. 7. A D3 run, n=1 both arms, through the session endpoint; figures in the notes.
